# Course Info

The Course Information application provides details about a course, including its name and the number of exercises in each part of the course. It also calculates and displays the total number of exercises.

<img src="https://github.com/dardangerguri/FullStackOpen/blob/main/project-media/Part1-CourseInfo.png" alt="Course Info" width="700" height="500"/>

## 🧠 How It Works

This project is built with React and renders course data stored in JavaScript objects. Data is passed to components as props, and the total number of exercises is calculated and displayed dynamically.

## ⚙️ Run

To run the project:

``` bash
	npm install
	npm run dev
```
